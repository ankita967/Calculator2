# Simple Calculator App

## Project Description

This project is a simple calculator application developed using Python.

The calculator performs basic mathematical operations and provides
a graphical user interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Calculation history
- Error handling
- Division by zero handling
- Invalid input handling
- GUI calculator

## Technologies Used

- Python
- Tkinter

## Python Concepts Used

- Variables
- input()
- if-else
- Functions
- Loops
- Lists
- try-except
- Arithmetic operators
- GUI programming

## Project Files

calculator.py
- Console-based calculator.

gui_calculator.py
- Graphical calculator application.

README.md
- Project documentation.

## How to Run

### Console Version

Open the terminal and run:

python calculator.py

### GUI Version

Open the terminal and run:

python gui_calculator.py
